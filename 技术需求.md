#### 3.1.2 向量嵌入服务

> ⚠️ **说明**：此模块已由 GraphRAG（知识图谱构建）自动包含，无需单独开发。
> GraphRAG 在构建知识图谱时会自动进行文本分块和向量化。

**需求描述**：将文本转换为向量表示，支持语义检索。

**技术要求**：
| 项目          | 选型                              | 说明           |
| ------------- | --------------------------------- | -------------- |
| Embedding模型 | text-embedding-ada-002 / m3e-base | 文本向量化     |
| 向量维度      | 1536 / 768                        | 根据模型确定   |
| 分块策略      | 512 tokens / 句子级               | 按语义单元切分 |
| 重叠窗口      | 50 tokens                         | 保持上下文连贯 |

**处理流程**：
```
原始文本 → 文本清洗 → 语义分块 → 向量化 → 存储
```

#### 3.2.2 检索策略

**混合检索策略**：
```python
def hybrid_search(query, top_k=10):
    # 1. 向量检索（语义相似）
    vector_results = vector_store.similarity_search(query, k=20)
    
    # 2. 关键词检索（精确匹配）
    keyword_results = elasticsearch.search(query, size=20)
    
    # 3. 知识图谱检索（关联知识）
    graph_results = knowledge_graph.query_entities(query)
    
    # 4. 结果融合与重排序
    merged = reciprocal_rank_fusion(
        vector_results, 
        keyword_results, 
        graph_results
    )
    
    # 5. 相关性重排序
    reranked = reranker.rerank(query, merged, top_k=10)
    
    return reranked
```

**检索参数配置**：
| 参数            | 值   | 说明                |
| --------------- | ---- | ------------------- |
| 向量检索top_k   | 20   | 初始召回数量        |
| 关键词检索top_k | 20   | 初始召回数量        |
| 最终返回数量    | 5-10 | 送入LLM的上下文数量 |
| 相似度阈值      | 0.7  | 过滤低相关内容      |

### 3.3 图片检索与展示模块

#### 3.3.1 图片与知识关联方案

**核心目标**：建立图片与知识点的明确关联，实现问答时自动推荐相关图片。

**整体流程**：
```
步骤1        步骤2        步骤3        步骤4        步骤5        步骤6
PDF解析  →  图片存储  →  AI描述   →  向量嵌入  →  关联构建  →  检索问答
```

**三层关联机制**：

| 关联层级       | 数据来源            | 可靠性 | 实现方式                 |
| -------------- | ------------------- | ------ | ------------------------ |
| **显式引用**   | 文本中"如图X-X所示" | ⭐⭐⭐⭐⭐  | 正则匹配图片编号         |
| **图注关键词** | 图片下方的图注文字  | ⭐⭐⭐⭐   | 提取图注关键词匹配知识点 |
| **语义相似**   | AI生成的图片描述    | ⭐⭐⭐    | 向量相似度计算           |

**关联权重设计**：
```
图片 img_001 的关联记录示例：
  知识点: "晶体结构"    权重: 0.95  来源: 显式引用

┌─────────┐   ┌───────────┐
│ 查文本  │   │ 查图片    │
│ Milvus  │   │ Milvus    │
│ Top-K=5 │   │ Top-K=3   │
└────┬────┘   └─────┬─────┘
     │              │
     ▼              ▼
┌──────────────────────────────┐
│  查关联表补充相关图片         │
│  chunk_0456 → img_120_001    │
│  (显式引用/高权重关联)        │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│  合并排序，返回给用户        │
│  文字回答 + 图片URL列表      │
└──────────────────────────────┘
```

**多模态检索方案**：

| 检索方式 | 技术                      | 说明                   |
| -------- | ------------------------- | ---------------------- |
| 文本搜图 | 智谱 embedding-3 (2048维) | 用图片描述文本搜索图片 |
| 图片搜图 | CLIP 图像Embedding        | 用相似图片搜索（可选） |
| 标签搜图 | 关键词匹配                | 用标签过滤图片         |
| 关联推荐 | 关联表查询                | 根据文本块查找关联图片 |

**向量集合设计（Milvus）**：
```
集合1: text_chunks（文本块）
  ├── chunk_id
  ├── document_id
  ├── text
  ├── embedding (2048维, 智谱embedding-3)
  └── metadata {page_num, section}

集合2: image_descriptions（图片描述）
  ├── image_id
  ├── document_id
  ├── description (AI生成或图注)
  ├── embedding (2048维, 统一维度)
  ├── image_url (MinIO路径)
  └── metadata {page_num, type, keywords}
```

**技术实现**：
```python
class ImageRetrievalService:
    def __init__(self):
        self.text_collection = MilvusCollection("text_chunks")
        self.image_collection = MilvusCollection("image_descriptions")
        self.relation_store = PostgreSQLTable("image_knowledge_relations")
        
    async def search_with_relations(self, query: str, top_k: int = 5):
        """带关联的图片检索"""
        # 1. 向量检索文本块
        text_results = await self.text_collection.search(query, top_k=5)
        
        # 2. 向量检索图片描述
        image_results = await self.image_collection.search(query, top_k=3)
        
        # 3. 查关联表，补充高权重关联图片
        for chunk in text_results:
            relations = await self.relation_store.query(
                chunk_id=chunk.id, 
                min_weight=0.7
            )
            for rel in relations:
                if rel.image_id not in [r.image_id for r in image_results]:
                    image_results.append(await self.get_image(rel.image_id))
        
        return text_results, image_results
```

### 3.4 PPT生成模块

#### 3.4.1 PPT生成流程

```
┌────────────┐    ┌────────────┐    ┌────────────┐    ┌────────────┐
│  主题输入  │───▶│  内容规划  │───▶│  素材准备  │───▶│  排版生成  │
└────────────┘    └────────────┘    └────────────┘    └────────────┘
                        │                  │
                        ▼                  ▼
                  ┌────────────┐    ┌────────────┐
                  │ 大纲生成   │    │ 图片检索   │
                  └────────────┘    └────────────┘
```

**详细步骤**：

1. **内容规划**
   - 调用LLM生成知识点大纲
   - 确定PPT页数和每页主题
   - 分配知识点到各页

2. **素材准备**
   - 从知识库检索相关文本内容
   - 检索配套图片资源
   - 提取关键定义、公式

3. **模板选择**
   - 提供多套PPT模板
   - 根据主题自动匹配模板风格

4. **排版生成**
   - 自动布局文字和图片
   - 统一字体、配色、间距
   - 添加页眉页脚、页码

#### 3.4.2 PPT模板规范

**模板类型**：
| 模板     | 适用场景 | 风格       |
| -------- | -------- | ---------- |
| 教学模板 | 概念讲解 | 简洁学术风 |
| 报告模板 | 学习报告 | 专业商务风 |
| 总结模板 | 知识复习 | 清晰明了风 |

**技术实现**：
```python
from pptx import Presentation
from pptx.util import Inches, Pt

class PPTGenerator:
    def __init__(self, template_path: str):
        self.prs = Presentation(template_path)
    
    async def generate(self, topic: str, content: dict):
        """生成PPT"""
        # 封面页
        self.add_title_slide(topic)
        
        # 目录页
        self.add_toc_slide(content["outline"])
        
        # 内容页
        for section in content["sections"]:
            self.add_content_slide(section)
        
        # 参考来源页
        self.add_reference_slide(content["sources"])
        
        return self.prs
    
    def add_content_slide(self, section):
        """添加内容页"""
        slide = self.prs.slides.add_slide(
            self.prs.slide_layouts[1]
        )
        # 标题
        slide.shapes.title.text = section["title"]
        # 正文
        self.add_bullet_points(slide, section["points"])
        # 图片
        if section.get("image"):
            self.add_image(slide, section["image"])
```
