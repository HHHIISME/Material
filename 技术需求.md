#### 3.2.2 检索策略

**混合检索策略**：
```python
def hybrid_search(query, top_k=10):
    # 1. 向量检索（语义相似）
    vector_results = vector_store.similarity_search(query, k=20)
    
    # 2. 关键词检索（精确匹配）
    keyword_results = elasticsearch.search(query, size=20)
    
    # 3. 知识图谱检索（关联知识）
    graph_results = knowledge_graph.query_entities(query)
    
    # 4. 结果融合与重排序
    merged = reciprocal_rank_fusion(
        vector_results, 
        keyword_results, 
        graph_results
    )
    
    # 5. 相关性重排序
    reranked = reranker.rerank(query, merged, top_k=10)
    
    return reranked
```

**检索参数配置**：
| 参数            | 值   | 说明                |
| --------------- | ---- | ------------------- |
| 向量检索top_k   | 20   | 初始召回数量        |
| 关键词检索top_k | 20   | 初始召回数量        |
| 最终返回数量    | 5-10 | 送入LLM的上下文数量 |
| 相似度阈值      | 0.7  | 过滤低相关内容      |

#### 3.3.2 图片检索技术

**多模态检索方案**：

| 检索方式   | 技术                 | 说明               |
| ---------- | -------------------- | ------------------ |
| 文本搜图   | CLIP / 文本Embedding | 用文字描述搜索图片 |
| 图片搜图   | 图像Embedding        | 用相似图片搜索     |
| 标签搜图   | 关键词匹配           | 用标签过滤图片     |
| 上下文关联 | LLM判断              | 根据问答上下文推荐 |

**技术实现**：
```python
class ImageRetrievalService:
    def __init__(self):
        self.clip_model = load_clip_model()
        self.image_store = MilvusCollection("images")
        
    async def search_by_text(self, query: str, top_k: int = 5):
        """文本搜图"""
        # 生成文本embedding
        text_embedding = self.clip_model.encode_text(query)
        # 向量检索
        results = self.image_store.search(text_embedding, top_k)
        return results
    
    async def search_by_context(self, query: str, answer: str):
        """上下文关联检索"""
        # 从回答中提取关键词
        keywords = await self.extract_keywords(answer)
        # 结合问题意图匹配图片类型
        image_type = self.classify_query_type(query)
        # 组合检索
        results = await self.multi_field_search(keywords, image_type)
        return results
```

### 3.4 PPT生成模块

#### 3.4.1 PPT生成流程

```
┌────────────┐    ┌────────────┐    ┌────────────┐    ┌────────────┐
│  主题输入  │───▶│  内容规划  │───▶│  素材准备  │───▶│  排版生成  │
└────────────┘    └────────────┘    └────────────┘    └────────────┘
                        │                  │
                        ▼                  ▼
                  ┌────────────┐    ┌────────────┐
                  │ 大纲生成   │    │ 图片检索   │
                  └────────────┘    └────────────┘
```

**详细步骤**：

1. **内容规划**
   - 调用LLM生成知识点大纲
   - 确定PPT页数和每页主题
   - 分配知识点到各页

2. **素材准备**
   - 从知识库检索相关文本内容
   - 检索配套图片资源
   - 提取关键定义、公式

3. **模板选择**
   - 提供多套PPT模板
   - 根据主题自动匹配模板风格

4. **排版生成**
   - 自动布局文字和图片
   - 统一字体、配色、间距
   - 添加页眉页脚、页码

---

#### 3.4.2 PPT模板规范

**模板类型**：
| 模板     | 适用场景 | 风格       |
| -------- | -------- | ---------- |
| 教学模板 | 概念讲解 | 简洁学术风 |
| 报告模板 | 学习报告 | 专业商务风 |
| 总结模板 | 知识复习 | 清晰明了风 |

**技术实现**：
```python
from pptx import Presentation
from pptx.util import Inches, Pt

class PPTGenerator:
    def __init__(self, template_path: str):
        self.prs = Presentation(template_path)
    
    async def generate(self, topic: str, content: dict):
        """生成PPT"""
        # 封面页
        self.add_title_slide(topic)
        
        # 目录页
        self.add_toc_slide(content["outline"])
        
        # 内容页
        for section in content["sections"]:
            self.add_content_slide(section)
        
        # 参考来源页
        self.add_reference_slide(content["sources"])
        
        return self.prs
    
    def add_content_slide(self, section):
        """添加内容页"""
        slide = self.prs.slides.add_slide(
            self.prs.slide_layouts[1]
        )
        # 标题
        slide.shapes.title.text = section["title"]
        # 正文
        self.add_bullet_points(slide, section["points"])
        # 图片
        if section.get("image"):
            self.add_image(slide, section["image"])
```

## 6. 部署架构

### 6.1 容器化部署

**Docker Compose 配置**：
```yaml
version: '3.8'

services:
  # 前端服务
  frontend:
    build: ./frontend
    ports:
      - "3000:80"
    depends_on:
      - backend

  # 后端API服务
  backend:
    build: ./backend
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgresql://...
      - MILVUS_HOST=milvus
    depends_on:
      - postgres
      - milvus
      - redis

  # 向量数据库
  milvus:
    image: milvusdb/milvus:latest
    ports:
      - "19530:19530"
    volumes:
      - milvus_data:/var/lib/milvus

  # 关系数据库
  postgres:
    image: postgres:15
    environment:
      POSTGRES_DB: materials_platform
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data

  # 缓存
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

  # 对象存储
  minio:
    image: minio/minio
    command: server /data --console-address ":9001"
    ports:
      - "9000:9000"
      - "9001:9001"
    volumes:
      - minio_data:/data

volumes:
  milvus_data:
  postgres_data:
  minio_data:
```
